## Method

An audit script reads the **staged file contents** — exactly what would be committed, rather than the working tree — and scans for two classes of problem:

**Secrets.** OpenAI, Anthropic, Google and Hugging Face API key shapes, GitHub tokens, AWS access keys, private key blocks, JWTs, and database connection strings carrying real credentials.

**Prohibited attribution.** `Co-Authored-By` trailers, "generated by AI", "AI-generated", "created/built/written with Claude", "Claude Code", and `Claude-Session`.

Every occurrence of the words *Anthropic* or *Claude* is additionally listed with its file, line and surrounding text so each can be classified by hand.

## Findings and actions

### Secrets

Four matches were found on the first pass, all in `tests/unit/security.test.ts`. All four were **fabricated fixtures** used to verify that the log redactor strips key-shaped strings — the test asserts the redactor works, so it necessarily contains something key-shaped.

Although harmless, literal key-shaped strings in a committed file trip automated secret scanners and waste a reviewer's time. The fixtures were rewritten to be assembled at runtime from a helper rather than written as literals. The tests still assert the same behaviour and still pass.

Re-scan after the change: **0 matches.**

### Attribution

**0 matches** on the first and every subsequent pass. No `Co-Authored-By` trailer, no "generated by" line, no AI-authorship claim anywhere in the repository, in any commit message, or in any file.

### Anthropic and Claude references

All 19 occurrences are **legitimate technical references to Anthropic as a supported model provider**, alongside OpenAI, Google Gemini, OpenRouter, Hugging Face and Ollama. None claims authorship, credit or contribution.

## Reproducing

```bash
git add -A
git log --format=fuller -30          # inspect author and committer on every commit
git log -30 --format="%B"            # inspect full commit message bodies
```

Then search the tree for the prohibited terms, excluding `node_modules`, `.next` and `.git`. On Windows PowerShell:

```powershell
Get-ChildItem -Recurse -File |
  Where-Object { $_.FullName -notmatch 'node_modules|\.next|\.git\\' } |
  Select-String -Pattern 'Co-Authored-By','Claude Code','AI-generated','built with Claude'
```

Any hit on *Anthropic* or *Claude* outside the table above should be classified before pushing.
